# Model Context Protocol (MCP)

## TL;DR

Le "USB-C de l'IA" : un protocole ouvert pour connecter n'importe quel LLM (comme Gemini) à vos données et outils locaux ou distants via une interface standardisée.

## À quoi ça sert

Aujourd'hui, chaque intégration entre une IA et une source de données (Google Drive, Slack, base de données SQL) est souvent faite sur mesure. Si vous changez d'IA, vous devez tout recommencer. 

Le MCP résout ce problème en introduisant une couche de standardisation :
- **Interopérabilité** : Une fois qu'un serveur MCP est écrit pour une donnée, il fonctionne avec n'importe quel client compatible (Gemini CLI, Claude Desktop, IDEs).
- **Contexte étendu** : Permet à Gemini d'accéder à des fichiers locaux, de la documentation ou des APIs en temps réel sans que ces données soient dans son jeu d'entraînement.
- **Actions concrètes** : Au-delà de la lecture, le MCP permet à l'agent d'exécuter des fonctions (outils) de manière sécurisée.

## Comment ça marche

L'architecture repose sur trois piliers :
- **Host** : L'application finale (ex: Gemini CLI). C'est elle qui orchestre l'interaction.
- **Client** : Un composant dans le Host qui communique avec les serveurs.
- **Server** : Un processus séparé qui expose des **Resources** (données), des **Tools** (actions) et des **Prompts**.

La communication se fait généralement via **JSON-RPC 2.0** sur un transport **stdio** (processus local) ou **HTTP/SSE**.

```ascii
[ Gemini CLI (Host/Client) ] <--- JSON-RPC (stdio) ---> [ Serveur MCP (ex: PostgreSQL) ]
```

## Exemple minimal

Configuration d'un serveur MCP dans le manifeste d'une extension Gemini (`gemini-extension.json`) :

```json
{
  "mcpServers": {
    "my-database": {
      "command": "node",
      "args": ["/chemin/vers/server/index.js"],
      "env": {
        "DB_CONNECTION_STRING": "..."
      }
    }
  }
}
```

## Pièges courants

- **Oubli de compilation** : Pour les serveurs en TypeScript, n'oubliez pas de lancer le `build` avant de les utiliser, sinon le fichier `.js` pointé par le manifeste sera manquant.
- **Authentification GitHub** : Beaucoup de serveurs MCP (comme `gemini-docs`) exigent un `GITHUB_TOKEN` pour éviter les limites d'appels API.
- **Variables d'environnement** : Les serveurs MCP ne tournent pas dans votre shell interactif ; assurez-vous de passer les variables nécessaires via le bloc `env` du manifeste.
- **Chemins relatifs** : Utilisez toujours des chemins absolus ou la variable `${extensionPath}` dans les configurations pour éviter les erreurs de "File not found".
- **Erreurs SSL** : Dans certains environnements restreints, les serveurs Node.js peuvent échouer à cause de certificats auto-signés ou manquants.
